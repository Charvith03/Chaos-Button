# CHAOS BUTTON 🎮

### How long can you survive the chaos?

Chaos Button is a small browser game I built using HTML, CSS and JavaScript.

The idea is simple — click the button as many times as you can before the 30-second timer runs out. Sounds easy, right?

Well... the button doesn't exactly want to cooperate. 😭

As you keep playing, things start getting more chaotic. The button moves, changes size and shape, fake buttons appear, the screen can shake, and other random events try to distract you.

## 🎮 How to Play

- Click the Chaos Button to score points.
- Keep clicking to build your combo.
- Watch out for the fake button!
- Adapt as the game gets harder.
- Try to beat your highest score.

You can also use:

- **M** → Toggle sound
- **T** → Toggle theme

The game runs for **30 seconds**. Your goal is simply to get the highest score you can.

## ✨ What I Built

- Moving and changing Chaos Button
- Combo and scoring system
- Increasing difficulty and levels
- Fake button distractions
- Random chaos events
- Sound effects
- Dark/light theme
- High-score saving
- Responsive design for different screens

## 🛠️ Built With

HTML • CSS • JavaScript

No frameworks or backend — just a simple standalone web project.
